# Songkhun Boonchaisuk

Assistant Professor of Geophysics and Head of the Geoscience Division at
**Mahidol University, Kanchanaburi Campus**, Thailand.

I image active faults and crustal structure in Thailand with magnetotellurics and seismology,
and I build machine-learning tools and teaching software for geoscience.

- 🌐 Website, publications and CV: **[songkhun.github.io](https://songkhun.github.io)**
- 📄 [Google Scholar](https://scholar.google.com/citations?user=r6LINnMAAAAJ) · [ORCID 0009-0002-4176-8449](https://orcid.org/0009-0002-4176-8449)

## Now

- **Three Pagodas Fault** — NRCT-funded magnetotelluric, gravity and magnetic study of an active fault in western Thailand (PI, 2026–2027)
- **Machine learning for geoscience** — resistivity-to-geotechnical prediction and satellite lineament mapping, following [SIP2025](https://github.com/Songkhun/SIP2025) at KIGAM, Korea
- **Teaching software** — gravity, resistivity inversion, 3-D MT viewers and an ML playground for my courses ([portfolio](https://songkhun.github.io/portfolio/))
